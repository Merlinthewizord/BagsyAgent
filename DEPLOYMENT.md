# Bagsy Deployment Guide

## Backend Deployment (Render)

The backend is configured to deploy automatically to Render using the `render.yaml` configuration.

### Step 1: Deploy to Render

1. Go to [Render Dashboard](https://dashboard.render.com/)
2. Click **"New +"** → **"Blueprint"**
3. Connect your GitHub repository (`Merlinthewizord/BagsyAgent`)
4. Select the branch: `claude/autonomous-token-trading-agent-PjdwK`
5. Render will automatically detect `render.yaml` and set up the service

### Step 2: Set Environment Variables

After the service is created, add the following environment variable in Render:

- **ANTHROPIC_API_KEY**: Your Anthropic API key (required for chat functionality)

Other environment variables are already configured in `render.yaml`:
- `FRONTEND_URL`: Already set to your Vercel deployment
- `BOT_API_KEY`: Auto-generated by Render
- `PORT`, `NODE_ENV`, `DATABASE_PATH`: Pre-configured

### Step 3: Copy Backend URL

Once deployed, Render will provide you with a URL like:
```
https://bagsy-backend.onrender.com
```

**Important**: Copy this URL - you'll need it for the frontend configuration.

### Step 4: Update Frontend Environment Variables

1. Go to your [Vercel Dashboard](https://vercel.com/dashboard)
2. Select the `bagsy-agent-8rw2` project
3. Go to **Settings** → **Environment Variables**
4. Add/Update: `NEXT_PUBLIC_API_URL` = `https://bagsy-backend.onrender.com` (use your actual Render URL)
5. Click **"Save"**
6. Trigger a new deployment from the Deployments tab

### Step 5: Verify Chat Functionality

1. Visit your frontend: https://bagsy-agent-8rw2.vercel.app
2. Open the chat interface
3. Send a message - it should now connect to the real Anthropic API through your deployed backend
4. No more fallback responses! 🎉

## Troubleshooting

### Chat still showing fallback responses
- Check that `NEXT_PUBLIC_API_URL` is set correctly in Vercel
- Verify the backend is running: visit `https://your-backend-url.onrender.com/health`
- Check Render logs for any errors
- Ensure `ANTHROPIC_API_KEY` is set in Render environment variables

### WebSocket connection issues
- Ensure `FRONTEND_URL` in Render matches your Vercel deployment URL exactly
- Check browser console for CORS errors

### Backend sleeping (Render free tier)
- Render free tier services sleep after 15 minutes of inactivity
- First request after sleep may take 30-60 seconds to wake up
- Upgrade to paid tier for 24/7 uptime
